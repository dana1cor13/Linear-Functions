What does f(x) mean?

f(x) means the output of function f when the input is x. It does not mean f multiplied by x.

Working backward

If f(x) = 11, what is x?

2x + 3 = 11  →  2x = 8  →  x = 4

Check: f(4) = 2(4) + 3 = 11.
